# TaskFlow - Master Your Productivity

TaskFlow is a modern workspace productivity and team collaboration web application designed to help users organize tasks, track progress, and manage projects seamlessly.

## Features
- Responsive Design: Fully optimized for desktops, tablets, and mobile devices.
- Dark / Light Mode: Instant theme switcher with local storage memory.
- Interactive UI: Smooth FAQ accordion, hero image slider, and modal popup for sign-ups.
- Form Validation:Real-time email validation for user registration.

##  Technologies Used
- HTML5
- CSS3 (Flexbox & Grid, Custom Variables)
- JavaScript (DOM Manipulation, ES6+)

## How to Run Locally
1. Clone the repository or download the ZIP file.
2. Open the project folder in your code editor (like VS Code).
3. Open `index.html` in any modern web browser to view the live site.
